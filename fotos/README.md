# Fotos dos serviços

Coloque as fotos originais aqui, cada uma na pasta do serviço correspondente.
Fotos de equipe ou do veículo vão em `geral/` (a primeira delas aparece no topo da home e em "Por que a SOS BH").

- Formatos aceitos: JPG, PNG ou WEBP, no tamanho original.
- A primeira foto de cada pasta entra no site automaticamente no próximo deploy (já otimizada).
- Para trocar uma foto que já está no site, apague o arquivo correspondente em `src/assets/fotos/`.
- Só fotos reais de serviços da SOS BH. Corte marcas d'água ("Shot on…") antes de subir.
